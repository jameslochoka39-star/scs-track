I set out to practise managing users, groups, organisational units and admin roles.

## 2. What I did, in order

I created a user, created a group, created an organisational unit, assigned a delegated role and then removed the role.

## 3. What went wrong, and how I fixed it

I had difficulty checking some of my files and correcting their locations. I used terminal commands to check and organise them.

## 4. How long it took, against the plan

The work took longer than I expected because I needed extra time to check the changes and fix mistakes.
