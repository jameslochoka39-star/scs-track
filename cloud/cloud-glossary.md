
# Cloud Glossary

| Term | In my own words | Found on — which screen |
|---|---|---|
| Region | A geographical area where AWS provides cloud services. | AWS Console region selector |
| availability zone | A separate location inside an AWS region where AWS resources operate. | AWS Console availability zones |
| console | A website where I access and manage AWS services. | AWS Management Console |
| IAM | A service that controls who can access AWS resources. | IAM dashboard |
| user | An identity that allows a person to access AWS services. | IAM Users screen |
| group | A collection of users who share permissions. | IAM User Groups screen |
| policy | A set of rules that controls access to AWS resources. | IAM Policies screen |
| instance | A virtual computer running in the cloud. | EC2 Instances screen — SCS2b.3 |
| bucket | A container for storing files and objects in AWS. | S3 Buckets screen — SCS2b.3 |
| security group | A virtual firewall that controls network traffic. | EC2 Security Groups screen — SCS2b.3 |
| key pair | Two related keys used to connect securely to a server. | EC2 Key Pairs screen — SCS2b.3 |
| SSH | A secure way to connect to another computer over a network. | Ubuntu terminal |
